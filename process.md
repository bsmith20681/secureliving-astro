# SEO Content Cluster Workflow

## 1. Create Content Cluster
- Use keyword research tool to identify one main (pillar) topic.
- Identify 2–5 supporting topics.
- Ensure each topic targets a distinct search intent.

## 2. Set Up Page Optimizer Pro (POP)
- Create a new page in Page Optimizer Pro.
- Select **POP Custom**.
- Enter primary keyword and have local claude skill give you the secondary keyword recomendations. 

## 3. Prepare AI Reference Packet
Gather the following materials:
- POP content brief PDF.
- Three competitor articles converted to Markdown. (just pass the urls to ai. The skill will do the rest)
- Relevant YouTube video transcripts.
- Any additional research or reference materials.

## 4. Generate and Compare Three Article Versions
- **Version 1:** Hemingway writes the initial article, followed by Fable optimizing and refining it.
- **Version 2:** Claude Opus writes the article.
- **Version 3:** Fable writes the article independently.

Compare all three versions for accuracy, readability, SEO optimization, and overall quality.

Use the **Hemingway → Fable version** as the primary draft, incorporating improvements from the other versions.

## 5. Review and Edit
- Fact-check claims and verify sources.
- Improve readability, structure, and formatting.
- Remove repetitive or unnecessary content.
- Ensure the article satisfies search intent.

## 6. Publish and Optimize
- Publish the article.
- Run the published URL through Page Optimizer Pro.
- Make final SEO adjustments based on POP recommendations.

## 7. Repeat for Supporting Articles
- Repeat steps 2–6 for each supporting topic.
- Skip the POP PDF when relevant search results are unavailable.
- **Complete each article from start to finish before beginning the next.**

## 8. Add Internal Links
Once the pillar and supporting articles are published:
- Use AI to identify relevant internal linking opportunities.
- Link the pillar article to supporting articles.
- Link supporting articles back to the pillar.
- Add contextual links between supporting articles where relevant.
- Review and publish the internal links.

---

**Workflow principle:** Complete one article through research, writing, editing, optimization, and publishing before moving to the next article.
