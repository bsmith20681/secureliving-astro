These are not suggestions. Check each one before you finish.

1. Length: between 2,900 and 3,400 words. A 1,400-word draft is a failure. Reach the length with detail from the transcripts (what each panel does, how installation went, what each camera records, exact prices and contract terms, who each system suits), not with filler.
2. Start with the title as an H1 line (`# ...`).
3. End with `## Frequently Asked Questions` containing the five questions listed in the brief, each as an H3 followed by a two- to four-sentence answer.
4. Use about 14 sections (H2s and H3s combined). Each H3 section needs at least 120 words.
5. Two tables, at least five lists, no dashes.
